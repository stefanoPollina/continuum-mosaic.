# CONTINUUM MOSAIC

### Modular synthesis, rhythmic exploration and live performance in the browser

**Continuum Mosaic** is an experimental, browser-based musical instrument and modular performance environment. It brings together multiple synthesis approaches, rhythm creation, expressive playing surfaces, effects, sequencing and signal routing in a single interactive workspace.

Rather than presenting a conventional single synthesiser, Continuum Mosaic is designed as an interconnected collection of sonic tools: a place to build sounds, develop patterns, explore textures and perform with them in real time.

> **Development status:** Active beta. This README describes the Continuum Mosaic Beta 0308 development branch. Features and behaviour may change as the instrument evolves.

## What is inside?

### Multiple synthesis engines

The environment contains an expanding family of synthesis and sound-design tools, including dual synthesiser workspaces, expanded synthesis controls, sound banks, modulation, acid-style sequencing and processing, and a multi-engine synthesis expansion. The interface also identifies a collection of **40+ engines and extensions**.

### Rhythms and instrument families

The **Rhythm Designer** and associated sequencers provide tools for programming and performing rhythmic material. Dedicated instrument and percussion areas include Earth Rhythms, electronic drums and other pitched and percussive voices. Certain instrument families offer expanded sequencing and expressive controls.

### Sequencing and performance

Continuum Mosaic combines step-based pattern creation with live performance surfaces. Features in the Beta 0308 interface include:

- Synth-specific **8-in-1 sequencers**, with eight note lanes and retrigger controls.
- Groove subdivision controls for rhythmic variation.
- Acid pattern banks and factory demonstrations.
- Expressive performance controls for pitch, modulation, sustain and layers.
- Live performance launchpad, performance command hub and unified pad deck interfaces.
- MIDI-related controls and integration points.

### Modular patching and routing

An **Interactive Modular Patch Bay** provides input and output sockets for exploring connections between parts of the environment. Signal-flow and control-routing interfaces help bring separate engines into a larger performance system.

### Mixing and effects

The interface includes a **48-channel Continuum Performance Mixer** and a collection of sound-shaping processors and effect sections, including:

- Reverb, phaser, compressor and multiband delay.
- Tape echo and dub-style send effects.
- Acid drive, saturation and clipping controls.
- Vintage amp and effects sections for synth output and live input.

Available effects and their routing depend on the relevant engine or section.

### Sonic textures and experimental tools

Continuum Mosaic also explores sustained and evolving sounds, including drone-oriented instruments and soundscapes. A live spectral visualiser and other visual experiments form part of the wider workspace; experimental visual features are not the central requirement for making sound.

## Getting started

1. Open the published Continuum Mosaic website, or open its `index.html` file in a modern browser.
2. Interact with the page to enable audio if your browser requires a user gesture.
3. Choose a synthesis or instrument section and explore its sound controls.
4. Use a sequencer, pattern bank or performance pad to create notes and rhythms.
5. Adjust the mixer and effects, and explore routing where supported.
6. Experiment with layering different engines into a larger performance.

**Tip:** Start with one sound source and one pattern, then bring additional instruments and processing into the mix. Some features may require browser permissions or connected MIDI/audio hardware.

## Design philosophy

Continuum Mosaic is built around **creative exploration rather than a fixed production workflow**. Its aim is to combine the immediacy of physical instruments with the flexibility of digital synthesis: accessible performance controls, deep sound-design possibilities and modular connections in one evolving interface.

The project favours preserving useful functionality while continually refining the layout, visual hierarchy and playability of the workspace.

## Related development: Continuum Rhythm Engine

The **Continuum Rhythm Engine** is being developed separately as a dedicated 40-track percussion and sequencing instrument. It is intended as a possible future component of the broader Continuum Mosaic ecosystem. Its existence does **not** mean it has already been integrated into Beta 0308.

## Technical notes

- Browser-based HTML and JavaScript application using Web Audio technologies.
- Designed to run as a standalone web page, including through GitHub Pages.
- Audio output and performance depend on the browser, device and audio configuration.
- MIDI functionality depends on compatible hardware and browser support.
- Beta software: individual modules may be experimental or incomplete.

## Development

Continuum Mosaic is an ongoing independent creative technology project. Each beta rollout explores improvements to synthesis, instrument design, sequencing, routing, usability and live performance while protecting established working features.
