EARTH RHYTHMS · LIVE PERCUSSION SYNTHESIS

Independent acoustic-inspired percussion engine, with its own level, mute, solo and six polymetric voices. No samples. All engines stay synchronised to one master clock; neither percussion engine controls the other.

Polymetre allocation gradually gives Earth Rhythms lanes independent cycle lengths without changing the master clock. Triplet subdivision plays three evenly spaced articulations per active step, while preserving each lane’s polymetric cycle. Tap steps to toggle. Each lane cycles at its own length (5–16 steps); probability adds live variation. BUILD and RELEASE adjust layers while playback continues. Sound is modelled electronically, not a faithful acoustic instrument reproduction.

LIVE INPUT · RHYTHMIC GATE (EXPERIMENTAL)

Microphone or audio-interface input → clocked gate → monitor and gated recording. The existing synth output remains unchanged. Use headphones to prevent feedback.

How does the Rhythmic Gate Lab work?

Signal path: Microphone or audio interface → input level → rhythmic gate → wet/dry mix → optional headphone monitoring and gated recording. This experiment does not alter the main synth output.

  • Enable Live Input: allow microphone access, ideally using headphones to avoid feedback.
  • Press Play: the gate follows the main sequencer clock. Lit steps let sound through; unlit steps attenuate it.
  • Pattern / step buttons: choose a starting rhythm, then tap individual steps to create a custom 16-step pattern.
  • Length: how long an active step stays open. Fade: opening time. Release: closing time.
  • Rotation: shifts the pattern around the 16 steps. Depth: how strongly closed steps are muted. Wet: proportion of gated versus original signal.
  • Monitor: hear the processed input live. Record Gated Input: capture the processed input, then stop and save the recording.

For a first test, use Every other 16th, Depth 100%, Wet 100%, Length 50–75%, and a short fade. Microphone permissions generally require HTTPS or localhost.

TAPE ECHO · EXPERIMENTAL

A separate echo processor after the live rhythmic gate. Recorded audio includes the delay when enabled. Your main synthesiser remains unaffected.

How does Tape Echo work?

The processed live input feeds a delay line. Feedback repeats the echo, Tone darkens each repeat, and Wow/Flutter introduces subtle tape-speed movement. Mix blends the original gated signal with the echoes. Tempo divisions follow the main BPM; Free Time uses milliseconds.

Start with Tape Quarter, Feedback 35%, Mix 30% and Wow 10%. For long dub trails, raise feedback gradually. The BYPASS switch passes the gated signal directly to recording and monitoring.

PARALLEL ROUTING: Live input splits into Gate and Tape Echo independently. Both feed the monitor and recorder. Neither processes the other.

CONTINUUM MOSAIC · MULTI-ENGINE CAPABILITIES

Not just two synthesisers: Continuum Mosaic combines two independent flagship synthesis engines, Synth A and Synth B, each with extensive oscillator, FM, phase-distortion, filtering, envelope, modulation and programmable sequencer facilities.

Two dedicated rhythmic systems: the Rhythm Designer and Electronic Drum Engine bring pattern programming, live drum pads and rhythm performance into the same musical environment.

A whole Earth Rhythms instrument family: live percussion synthesis, handpan, tank drum, balafon and a resonant drone with an experimental didgeridoo-style formant sequencer. These are playable instrument systems, not all separately labelled synthesis engines.

One self-contained HTML instrument: a multi-engine sound-design, composition and performance environment built to be played, explored and developed.

CONTINUUM MOSAIC · INSTRUMENT & WORKSPACE GUIDE

Getting started: Select ENABLE AUDIO to activate the sound engine, then use the shared PLAY and STOP controls for clocked patterns. Individual instruments also offer live playing and, where provided, independent sequencer controls.

Synthesis: Synth A and Synth B have independent sound-design controls, including oscillator, modulation, FM / phase distortion, filters, envelopes and sequencer programming. Additional synthesis and performance modules extend the workspace.

Rhythm and Earth Rhythms: Programme the Rhythm Designer and Electronic Drum Engine, or play the Earth Rhythms percussion pads. The melodic family includes the handpan, tank drum and balafon, followed by the resonant drone and its optional didgeridoo formant sequencer.

Performance and connectivity: Use the performance keyboard and instrument sequencers to trigger musical parts. External MIDI input, performance presets, shared effects and signal-flow controls are provided in their respective sections.

Modular patching: In the modular rack, connect an output socket to a compatible input socket; select a cable to remove it. Drag module headings to reposition them, or use AUTO ARRANGE to tidy the rack. Patch routing and live audio controls are separate from visual panel placement.

Exploration: Optional experimental instruments and visual studies have their own panels. Expand only the sections you need; the main workspace remains available without opening this guide.
